# Security Policy

## Supported Versions

Security updates and critical patches are actively applied to the latest `main` branch.

| Version | Supported |
|---|---|
| `v1.3.x` (main) | ✅ Yes |
| `< 1.3` | ❌ No |

---

## Reporting a Vulnerability

If you discover a security vulnerability in ConfMan, please do not disclose it publicly via issue trackers or discussions.

Instead, please report the vulnerability privately to the repository maintainer:
- Open a **GitHub Security Advisory** in the repository's "Security" tab, or
- Email the security maintainer directly.

Please include:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept code to reproduce the issue.
- Any suggested mitigations.

You will receive an acknowledgment within 48 hours, followed by updates as the issue is investigated and patched.
